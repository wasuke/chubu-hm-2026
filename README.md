# NEBUTA GS 講義用VRビューア

## 目的

1. 通常表示で指を使ってGaussian Splatting空間の視点を決める。
2. 「VR表示」を押す。
3. スマートフォンを紙製VRゴーグルへ入れる。
4. 端末のジャイロ／方向センサーで3DoF閲覧する。

VR表示は左右眼を別カメラで描画するため、単なる同一画像の二分割ではなく、簡易的な両眼視差を付けています。

## ファイル

- `index.html` UI
- `app.js` GS表示・タッチ操作・Cardboard表示・端末方向センサー
- `assets/scene.ply` 元の `NEBUTA_Splat.ssproj` から抽出したGaussian Splattingデータ

## 公開方法

このフォルダをそのままGitHubリポジトリへ置き、GitHub Pagesで公開してください。`file://` でindex.htmlを直接開く方法は使わず、HTTPSのWebサーバからアクセスしてください。

## 操作

通常表示：
- 1本指ドラッグ：視点を回転
- 2本指：ズーム／移動
- 「初期位置」：SuperSplatプロジェクトに保存されていた初期視点へ戻す

VR表示：
- 「VR表示」をタップ
- iPhone等で求められた場合は「動作と方向」へのアクセスを許可
- 横画面にして紙製ゴーグルへ装着
- 首を上下左右へ向けると3DoFで視点が変化
- 画面上部中央の「VRを終了」で通常表示へ戻る

## 授業での説明

通常表示で指を使って視点を決めたあと、VR表示へ切り替える構成です。

- 通常操作：自分でカメラ位置を変更
- VR表示：その位置を固定したまま頭の「回転」を取得
- 左右眼：少し異なるカメラ位置からGSを描画

このため、「3DoF」「両眼視差」を一つのデモで説明できます。

## 調整箇所

`app.js` の以下の値で左右眼の間隔を調整できます。

```js
stereo.eyeSep = 0.0055;
```

立体感が強すぎる場合は `0.003` 前後、弱い場合は `0.007` 前後を試してください。このGSは実寸スケールとは限らないため、一般的な人間の瞳孔間距離をそのまま指定していません。

## 注意

- 初回は約66MBのPLYを読み込みます。模擬講義では事前に各端末で一度開いておく方が安全です。
- iOS Safariでは方向センサーの許可はボタン操作から要求する必要があります。そのため「VR表示」ボタンを入口にしています。
- GitHub PagesではSharedArrayBuffer用の特殊ヘッダを自由に設定しにくいため、`sharedMemoryForWorkers: false` にしています。
- これはCardboard向けの3DoF版です。位置トラッキングによる6DoFは含んでいません。
